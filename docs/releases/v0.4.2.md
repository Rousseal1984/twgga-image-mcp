# twgga-image-mcp v0.4.2

修一处 Windows 上客户看得到的路径回归。

## 修了什么

出图返回的 `saved.path`，以及若干报错文案里嵌的路径，在 Windows 上带着
`fs::canonicalize` 的扩展前缀：

```
\?\C:\Users\你\Pictures\twgga-out\gen_1788491877968225300_1.png
```

现在是干净路径：

```
C:\Users\你\Pictures\twgga-out\gen_1788491877968225300_1.png
```

这不是一直如此 —— 仓库自带的 `mock-cases-before-path-refactor.json` 记录的
重构前形态就是干净路径，说明这是后来引入的回归。共八处输出边界补上了显示层
转换：`saved.path` 本身，以及 `TWGGA_INPUT_ROOT`、save root、`save_dir`、
锁文件这几类报错里的路径。

macOS 与 Linux 不受影响，那里本来就没有这个前缀。

## 会不会影响我现有的用法

不会。工具名、参数、返回结构、落盘位置、计费口径都没变，图还是写到同一个地方。
只是返回给你的那串路径不再带前缀。如果你的脚本在解析 `saved.path`，去掉前缀
之后它更像一条普通的 Windows 路径，通常只会更好用。

## 该不该升

Windows 用户建议升。macOS / Linux 用户升不升都一样，两版行为完全相同。

升级方式：下载新版二进制，再跑一次 `install`。`install` 会把二进制复制到一个
稳定目录、客户端配置指向的是那个副本，所以光覆盖下载处不会生效；不确定是否
生效就跑 `doctor`，它会直接告诉你副本还是旧版本。
