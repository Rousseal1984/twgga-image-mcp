# twgga-image-mcp v0.5.0

三件新东西：同一张图可以接着改；API Key 存进系统凭据库，不再留在配置文件里；一行命令就能安装和升级。

## 升级方式

重新运行一行安装命令即可，已保存的 Key 不用重新输入。

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/Rousseal1984/twgga-image-mcp/main/scripts/install.ps1 | iex
```

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/Rousseal1984/twgga-image-mcp/main/scripts/install.sh | sh
```

完成后重新连接 MCP，调用 `server_info` 确认 `version` 为 `0.5.0`。原来的方式（下载程序、运行 `install --yes`）也照样可用。

## 连续编辑

`image_generate` 与 `image_edit` 新增 `session_id`、`parent_revision`、`context` 三个可选参数。

- 首次传 `session_id="new"`，之后传返回的 `session.id`，就能在上一版图片上继续改，MCP 自动上传那一版图片并带上之前的要求。
- 同一聊天里可以有多个会话：小猫一个、海景一个，回到小猫时用小猫的 ID。
- 会话保存在你电脑上的 `TWGGA_SAVE_DIR_ROOT/.twgga-sessions`，重启 MCP 后可以继续；失败的调用不推进版本。
- 不传 `session_id` 时行为与 v0.4.3 完全一样。

工具描述里写明了什么时候开新会话、什么时候沿用旧会话，客户端里的 AI 会照着选。

## API Key 存进系统凭据库

- Key 存在 Windows 凭据管理器、macOS 钥匙串或 Linux Secret Service，**不再写进任何客户端配置文件**。MCP 每次启动自己读取。
- 安装时先看环境变量 `TWGGA_API_KEY`，再看凭据库；都没有就在终端提示输入一次（不显示）。旧配置里的明文 Key 会先迁移进凭据库，再从配置里删除。
- 新增 `credentials set`（更换 Key）和 `credentials authorize`（macOS 授权已有 Key）。
- 这也修好了一个老问题：v0.4.3 按站内文档在 PowerShell 里临时设置 `TWGGA_API_KEY` 再 `install`，Key 只在那个窗口有效，之后从桌面打开客户端时 MCP 拿不到 Key。现在 Key 存进凭据库，任何方式启动都能读到。

## 其他改进

- 新增可选参数 `output_format`（`png` / `jpeg` / `webp`），省略时不发送；返回的 `saved[].format` 按文件内容判定。
- 兼容新版 Claude Code 的工具发现协议。此前在使用 2026-07-28 协议的客户端里可能显示「已连接 · 0 个工具」。
- 安装器与测试全部改为 Rust，不再需要也不再包含 Python。
- 若服务端返回 GIF，会逐帧校验并防止解压炸弹；本站不提供动图请求。
- 会话返回的 `session.input_path` 在 Windows 上不带 `\\?\` 前缀，与 `saved.path` 一致。

## 没有变的

- 仍只有 `gpt-image-2` 一个模型，不按尺寸切换线路。输出约 157 万像素，与请求的 `size` 无关；画幅请写进 prompt。
- 五个工具的名字与原有参数不变，不传新参数时请求与 v0.4.3 相同。
- 1K 请求的 HTTP 错误仍不在 MCP 侧重试，2K/4K 仍串行排队。

## 验证

- 离线：格式、两轮严格 Clippy、全部 Rust 测试、冒烟与压力测试、源码审计、依赖安全审计均通过，没有发出付费请求。
- Windows 本机：安装器把 Key 写入凭据管理器、配置文件里没有明文 Key、新进程在没有环境变量的情况下读回 Key，均已实测。
- 在线（2026-11-09，TWGGA 生产接口，Windows）：生成一张蓝色陶瓷杯开会话，重启 MCP 后只凭会话 ID 改成黄色，形状、把手、位置和背景都保留，两次请求均为 HTTP 200。
