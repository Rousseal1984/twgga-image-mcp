# 图片会话在用户电脑上的保存与管理

会话记忆是 MCP 保存在你电脑上的本地 JSON 文件，不是服务端的 token/KV 缓存。
每次成功只记录当前指令、有效约束、设置和图片路径，不把图片或完整 base64 放进 JSON。
图片本身独立保存，每个成功版本通常新增一张图片。

## 保存位置

| 内容 | 位置与用途 |
| --- | --- |
| 会话记忆 | `TWGGA_SAVE_DIR_ROOT/.twgga-sessions/edit_<id>/revision-<n>.json` |
| 图片 | 正常输出目录，由 `saved.path` 返回；`TWGGA_SAVE_DIR` 必须位于输出根目录内 |
| 并发锁 | 会话目录的 `.lock`、`~/.cache/twgga-image/bigsize.lock`；锁文件不保存图片或历史 |
| 请求临时文件 | 请求期间使用的输入快照与输出临时文件，正常完成、失败和取消时释放 |

未自定义时，输出根目录是 `~/Pictures/twgga-out`。客户端配置可能覆盖它，先通过 `server_info`
查看实际目录。改动根目录后，旧会话不会自动迁移；记录里的图片路径是绝对路径。
进程被强制终止或机器断电时可能遗留临时文件，当前没有启动时自动扫除功能。

## 占用大小

以下数字由上游开源项目 micu-image-mcp 于 2026-10-09 在 Linux 上用真实 Rust MCP 与本地 HTTP 替身测得，没有发出付费请求；它们只取决于约束长度与版本数，与站点无关。
以下只统计版本 JSON，不含目录、锁和图片；数据块占用依文件系统变化。

| 会话约束示例 | 成功轮数 | JSON 合计 | JSON 数据块占用 |
| --- | ---: | ---: | ---: |
| 人物、衣服、背景、构图等短约束 | 20 | 11.1 KiB | 80 KiB |
| 同上 | 128 | 71.4 KiB | 512 KiB |
| 约 6440 字符的较长约束 | 20 | 386.4 KiB | 400 KiB |
| 同上 | 128 | 2.42 MiB | 2.50 MiB |

每条记录硬上限 256 KiB，每会话最多 128 个版本，因此版本 JSON 的理论总量上限为 32 MiB。
有效约束在每轮记录中保存完整当前值，较长约束会重复占用空间；历史指令每轮只新增本轮内容。

图片通常是主要占用：如果每张 1.5 MiB，20 个成功版本约 30 MiB，128 个版本约 192 MiB。
这只是容量估算，实际以 `saved.size_bytes` 为准。目前没有会话总数上限、整体磁盘配额、TTL 或自动清理。
没有成功版本的初始请求也可能留下空会话目录和锁文件。

## 当前如何管理

macOS/Linux 可通过 Finder、文件管理器或终端查看实际输出目录。
Finder 用 `Command+Shift+.` 显示 `.twgga-sessions`。Windows 可在资源管理器地址栏直接进入该目录。

```bash
# 按 server_info 返回值替换；以下是默认路径。
twgga_root="$HOME/Pictures/twgga-out"
du -sh "$twgga_root" "$twgga_root/.twgga-sessions"
```

- 要继续编辑或保留回滚：保留会话目录、全部版本 JSON 和对应图片。先结束正在执行的请求再归档。
- 已结束且只需要作品：先复制最终图片到作品目录，再将该会话目录及确认不再需要的中间图片移到归档或废纸篓。
- 只清除记忆：归档整个 `edit_<id>` 目录；图片仍保留，可通过图片路径和 `session_id="new"` 重新开始。
- 恢复归档：将会话目录及图片恢复到原位置，再使用原 ID。只迁移 JSON 或只删除祖先 JSON 会破坏恢复链路。

当前没有会话管理面板或清理 CLI。不要将整个输出根目录当作可随时删除的普通缓存；它包含用户作品。
不要在请求运行时删除锁文件，否则新的请求可能绕过原锁而同时发出。

## 质量档位

这里的参数名是 `quality`，不是 Codex 的 `reasoning_effort`。本站只有 gpt-image-2，MCP 接受
`auto/low/medium/high`，省略时由服务端决定。

可复跑的 Rust 质量矩阵只连接固定的 TWGGA 域名，逐项调用 Rust MCP 的生成、编辑工具。
程序用本机回传代理统计实际发出的图片 POST，包括重试；凭据只保留在内存，不进入参数、日志或报告。
每项独立请求，记录成功状态、耗时、尺寸和实际请求数。

```bash
# 仅列出计划；不读凭据，不发网络请求。
cargo xtask quality-matrix

# 在线模式需另行授权，通过 stdin JSON 提供凭据，明确 --live、--limit 和新的 --output。
# 字段与守卫见 docs/rust-only-development.md；这里不执行在线请求。
```

1K 计划共 10 项（生成、编辑 × 省略与四档质量）。在线模式每项都按实际出图张数计费，
鉴权失败时停止，不继续产生图片请求。
